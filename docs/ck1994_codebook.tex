\section*{Overview}
The raw file \texttt{public.dat} contains \textbf{410 observations} (one row per store),
each with \textbf{46 whitespace-delimited fields}. Missing values are coded as a literal
period (\texttt{.}). Each row contains data from \emph{both} survey waves: Wave~1
(February--March 1992, pre minimum-wage increase) and Wave~2 (November--December 1992,
post increase). Wave-2 variables share the same name as their Wave-1 counterpart with a
trailing \texttt{2} (e.g. \texttt{EMPFT} vs.\ \texttt{EMPFT2}).

\subsection*{Key derived variable: FTE employment}
Full-time-equivalent employment, as defined in Card \& Krueger (1994, p. 775):
\[
\text{FTE} = \text{EMPFT} + \text{NMGRS} + 0.5 \times \text{EMPPT}
\]

\section*{Codes}

\subsection*{Meal program (MEALS / MEALS2)}
\begin{itemize}
  \item 0 = none
  \item 1 = free meals
  \item 2 = reduced-price meals
  \item 3 = both free and reduced-price meals
\end{itemize}

\subsection*{Second-interview status (STATUS2)}
\begin{itemize}
  \item 0 = refused second interview ($n=1$)
  \item 1 = answered second interview ($n=399$)
  \item 2 = closed for renovations ($n=2$)
  \item 3 = closed permanently ($n=6$)
  \item 4 = closed for highway construction ($n=1$)
  \item 5 = closed due to mall fire ($n=1$)
\end{itemize}
